下面给你一套**可直接落地的前后端接口交互格式规范**，覆盖 **增 / 删 / 改 / 查（CRUD）**，包含 **请求格式 + 返回格式 + 字段说明**。

- ✅ 适用于 **RESTful 风格**
- ✅ JSON 交互
- ✅ 前后端通用规范

---

## 一、通用约定

### 1️⃣ 基础 URL

```http
https://api.example.com/v1
```

### 2️⃣ 公共请求头

```http
Content-Type: application/json
Authorization: Bearer {token}
```

### 3️⃣ 公共返回结构（统一）

```json
{
  "code": 0,
  "msg": "success",
  "data": {},
  "success": true
}
```

### 4️⃣ 公共返回JAVA结构封装

```java
@Data
@AllArgsConstructor
@NoArgsConstructor
public class ApiResponse<T> {

    private int code;
    private String msg;
    private T data;
    private boolean success;

    public static <T> ApiResponse<T> success(T data) {
        return new ApiResponse<>(0, "success", data, true);
    }

    public static <T> ApiResponse<T> fail(int code, String msg) {
        return new ApiResponse<>(code, msg, null, false);
    }
}
```

| 字段    | 说明                       |
| ------- | -------------------------- |
| code    | 状态码（0=成功，非0=失败） |
| msg     | 提示信息                   |
| data    | 业务数据                   |
| success | 是否成功                   |

## 二、查询（Read）

### ✅ 单条查询（GET）

**前端请求**

```http
GET /users/1001
```

**后端JAVA接收**

```java
@GetMapping("/users/{id}")
public ApiResponse<UserVO> getUserById(@PathVariable Long id) {
    UserVO user = userService.getById(id);
    return ApiResponse.success(user);
}
```

**接口返回**

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 1001,
    "username": "zhangsan",
    "email": "zs@example.com",
    "status": 1,
    "createdAt": "2025-01-01 10:00:00"
  }
}
```

---

### ✅ 分页查询（GET）

**前端请求**

```http
GET /users?current=1&size=10&keyword=zhang
```

**后端JAVA-DTO（可选）**

```java
@Data
public class PageRequest {
    @Min(1)
    private Integer current = 1;

    @Min(1)
    private Integer size = 10;

    private String keyword;
}
```

**后端JAVA-Controller**

```java
@GetMapping("/users")
public ApiResponse<PageResult<UserVO>> listUsers(PageRequest pageRequest) {

    PageResult<UserVO> page = userService.pageQuery(
            pageRequest.getCurrent(),
            pageRequest.getSize(),
            pageRequest.getKeyword()
    );

    return ApiResponse.success(page);
}
```

**后端JAVA-分页结果封装**

```java
@Data
public class PageResult<T> {
    private long current;
    private long size;
    private long total;
    private List<T> data;
}
```

**接口返回**

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "current": 1,
    "size": 10,
    "total": 100,
    "data": [
      {
        "id": 1001,
        "username": "zhangsan",
        "status": 1
      }
    ]
  }
}
```

## 三、新增（Create）

### ✅ 新增数据（POST）

**请求**

```http
POST /users
```

```json
{
  "username": "lisi",
  "password": "123456",
  "email": "lisi@example.com"
}
```

**后端JAVA-DTO**

```java
@Data
public class CreateUserDTO {

    @NotBlank(message = "用户名不能为空")
    private String username;

    @NotBlank(message = "密码不能为空")
    private String password;

    @Email(message = "邮箱格式不正确")
    private String email;
}
```

**后端JAVA-Controller**

```java
@PostMapping("/users")
public ApiResponse<Long> createUser(@RequestBody @Valid CreateUserDTO dto) {
    Long userId = userService.create(dto);
    return ApiResponse.success(userId);
}
```

**接口返回**

```json
{
  "code": 0,
  "msg": "创建成功",
  "data": {
    "id": 1002
  }
}
```

## 四、修改（Update）

**请求**

```http

```

## 六、错误返回规范

```json
{
  "code": 40001,
  "msg": "参数校验失败",
  "data": {
    "field": "email",
    "reason": "邮箱格式不正确"
  },
  "success": true
}
```

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ApiResponse<?> handleValidException(MethodArgumentNotValidException ex) {

        FieldError error = ex.getBindingResult().getFieldError();
        return ApiResponse.fail(40000, error.getDefaultMessage());
    }

    @ExceptionHandler(BusinessException.class)
    public ApiResponse<?> handleBusinessException(BusinessException ex) {
        return ApiResponse.fail(ex.getCode(), ex.getMessage());
    }
}
```

### 常见错误码

| code  | 含义       |
| ----- | ---------- |
| 0     | 成功       |
| 40000 | 参数错误   |
| 40100 | 未登录     |
| 40300 | 无权限     |
| 40400 | 资源不存在 |
| 50000 | 系统异常   |
