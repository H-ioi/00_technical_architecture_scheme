# admin-web 前端自动化测试方案

## 一、方案概述

### 1.1 项目现状分析

| 维度 | 现状 |
|------|------|
| 技术栈 | Vue 3 + Vite + TypeScript + Pinia + Element Plus + uni-ui-lib |
| 核心风险点 | 后端接口字段格式不统一（snake_case / camelCase 混用），存在大量防御性兼容代码 |
| 业务复杂度 | 考勤（请假/销假/放行条/流程）、校车、活动、邮件、权限等模块 |
| 当前测试状态 | 无任何测试配置或测试文件 |
| 可测试代码量 | `src/utils/*` (8 文件)、`src/composables/*` (7 文件)、`views/**/*.{ts}` (若干)、`api/modules/*` (40+ API) |

### 1.2 测试目标

```
核心目标：建立分层测试体系，保障业务逻辑正确性，为重构和迭代提供安全网
├── 防御性代码防护 → api-response-normalize.ts / holiday-utils.ts 等归一化逻辑
├── 工具函数验证   → tool.ts / download.ts / form-display.ts 等
├── Composable 行为 → 状态管理、副作用、生命周期钩子
├── 图表数据转换   → build-chart-options.ts 配置生成
└── CI 卡点         → PR 合入前自动运行测试，阻止低级错误
```

### 1.3 测试原则

| 原则 | 说明 |
|------|------|
| **投入产出优先** | 先测高价值、高风险的纯逻辑代码，不测第三方组件 |
| **快速反馈优先** | 单元测试 < 100ms/个，全量执行 < 30s |
| **渐进式覆盖** | 分三批推进，每批有明确的完成标准 |
| **测试即文档** | 测试用例应清晰表达函数的预期行为 |

## 二、技术选型与工具链

### 2.1 核心工具

```json
{
  "devDependencies": {
    "vitest": "^3.0.0",             // 测试运行器（Vite 原生集成）
    "@vue/test-utils": "^2.x",      // Vue 组件测试工具
    "jsdom": "^24.x",               // DOM 模拟环境
    "@vitest/coverage-v8": "^3.0.0" // 覆盖率报告（V8 引擎）
  }
}
```

选型理由：
- **Vitest** vs Jest：与 Vite 配置零重复复用，启动速度极快（<500ms），ESM 原生支持
- **@vue/test-utils**：Vue 官方维护，API 稳定
- **jsdom**：轻量 DOM 模拟，满足大部分组件测试需求
- **coverage-v8**：比 Istanbul 更快更准确

### 2.2 可选增强工具（后续按需引入）

| 工具 | 用途 | 引入时机 |
|------|------|----------|
| `msw` | Mock Service Worker，模拟真实网络请求 | 第二批 |
| `@testing-library/vue` | 更偏用户行为的测试风格（可选替代 test-utils） | 不强制 |
| `vitest-mock-extended` | 类型安全的 Mock 创建 | 第一批即可引入 |

## 三、目录结构规范

> 所有测试文件统一放置在 `src/__tests__/` 目录下，按源码模块分子目录，**不对源码目录产生污染**。

```
└── src/

        ├── utils/
```

**设计原则：**
- 测试文件使用 **相对路径** 导入源码（如 `../../utils/tool`），不依赖 `@/` 别名
- 需要 jsdom 环境的测试文件在文件头部添加 `// @vitest-environment jsdom` 指令
- 目录结构镜像 `src/` 的模块划分，便于快速定位

**命名规范：**

| 场景 | 命名格式 | 示例 |
|------|----------|------|
| 工具函数/纯逻辑 | `*.test.ts` | `tool.test.ts` |
| Vue 组件 | `*.spec.ts` | `list-table-empty.spec.ts` |
| Composable | `*.test.ts` | `use-tab-query-sync.test.ts` |
| 全局 setup | `setup.ts` | `setup.ts` |

## 四、Vitest 配置文件

```typescript
// admin-web/vitest.config.ts
import { defineConfig } from 'vitest/config'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],

  test: {
    // ========== 环境 ==========
    environment: 'jsdom',          // DOM 模拟环境（默认）
    globals: false,                // 不自动注入，使用显式 import

    // ========== 文件匹配（统一 __tests__ 目录）==========
    include: ['src/__tests__/**/*.test.ts', 'src/__tests__/**/*.spec.ts'],
    exclude: ['node_modules', 'dist', 'coverage'],

    // ========== 全局 Setup ==========
    setupFiles: ['./src/__tests__/setup.ts'],

    // ========== 超时控制 ==========
    testTimeout: 10000,            // 单个用例最大 10s
    hookTimeout: 10000,            // hook 最大 10s

    // ========== 覆盖率配置 ==========
    coverage: {
      provider: 'v8',
      reporter: ['text', 'text-summary', 'json', 'html', 'lcov'],

      include: [
        'src/utils/**/*.ts',
        'src/composables/**/*.ts',
        'src/views/**/*.ts'
      ],
      exclude: [
        '**/*.d.ts',
        '**/__tests__/**',
        'src/types/**'
      ]
    }
  }
})
```

> **注意**：
> - 测试文件使用相对路径导入（`../../utils/tool`），无需配置 `@/` alias
> - `globals: false` 要求测试文件显式 `import { describe, it, expect, vi } from 'vitest'`
> - 需要 jsdom 环境的文件在顶部添加 `// @vitest-environment jsdom`（如 `download.test.ts`）
> - vitest 采用 **v3.0.0** 稳定版（v4.x 在 Windows 下存在兼容问题）

### 全局 Setup 文件

```typescript
// admin-web/src/__tests__/setup.ts
import { vi, afterEach } from 'vitest'

afterEach(() => {
  vi.restoreAllMocks()
})
```

> 保持 setup 轻量：仅做 mock 清理。特殊环境的 mock（如 `URL.createObjectURL`、`uni-ui-lib`）在各测试文件内部 `beforeAll` 中按需配置。

### 6.1 工具函数测试规范

以 `tool.ts` 为例的标准模板：

```typescript
// src/__tests__/utils/tool.test.ts
import { describe, it, expect } from 'vitest'
import {
  dateFormat,
  groupSeparator,
  coerceIdList,
  getUUID
} from '../../utils/tool'

describe('tool.ts', () => {

  // ==================== dateFormat ====================
  describe('dateFormat', () => {
    it('应返回 yyyy-MM-dd hh:mm:ss 格式的日期字符串', () => {
      const result = dateFormat(new Date('2024-01-15T08:30:00'))
      expect(result).toBe('2024-01-15 08:30:00')
    })

    it('应支持自定义格式模板', () => {
      const result = dateFormat(new Date('2024-03-05'), 'yyyy/MM/dd')
      expect(result).toBe('2024/03/05')
    })

    it('无效日期输入应返回空字符串', () => {
      expect(dateFormat('invalid-date')).toBe('')
      expect(dateFormat(NaN)).toBe('')
    })

    it('应处理时间戳输入', () => {
      const ts = new Date('2024-06-01T00:00:00').getTime()
      expect(dateFormat(ts)).toContain('2024-06-01')
    })
  })

  // ==================== groupSeparator ====================
  describe('groupSeparator', () => {
    it('应对数字添加千分位', () => {
      expect(groupSeparator(1234567)).toBe('1,234,567')
    })

    it('应保留小数位', () => {
      expect(groupSeparator(1234.5678)).toBe('1,234.568')
    })

    it('非数字原样返回', () => {
      expect(groupSeparator('abc')).toBe('abc')
      expect(groupSeparator(null as any)).toBe('')
    })

    it('应处理字符串形式的数字', () => {
      expect(groupSeparator('9999')).toBe('9,999')
    })
  })

  // ==================== coerceIdList ====================
  describe('coerceIdList', () => {
    it('单个值应包装为数组', () => {
      expect(coerceIdList(42)).toEqual([42])
      expect(coerceIdList('abc')).toEqual(['abc'])
    })

    it('数组应过滤空值', () => {
      expect(coerceIdList([1, '', null, undefined, 2])).toEqual([1, 2])
    })

    it('空值应返回空数组', () => {
      expect(coerceIdList(null)).toEqual([])
      expect(coerceIdList(undefined)).toEqual([])
      expect(coerceIdList('')).toEqual([])
    })
  })

  // ==================== getUUID ====================
  describe('getUUID', () => {
    it('应生成指定长度的随机字符串', () => {
      const uuid = getUUID('', 16)
      expect(uuid.length).toBe(16)
      expect(uuid).toMatch(/^[A-Z0-9]+$/)
    })

    it('应支持 name 前缀', () => {
      const uuid = getUUID('ORDER', 8)
      expect(uuid.startsWith('ORDER-')).toBe(true)
      expect(uuid.length).toBe(14)  // "ORDER-" + 8
    })

    it('长度小于 1 应抛出错误', () => {
      expect(() => getUUID('', 0)).toThrow()
      expect(() => getUUID('', -1)).toThrow()
    })
  })
})
```

### 6.2 数据归一化测试规范（重点！）

这是项目的**最高价值测试区域**：

```typescript
// src/__tests__/views/attendance/holiday-utils.test.ts
import { describe, it, expect } from 'vitest'
import {
  normalizeHolidayListRow,
  normalizeHolidayReturnRow
} from '../../../views/attendance/holiday/holiday-utils'

describe('holiday-utils.ts', () => {

  // ==================== normalizeHolidayListRow ====================
  describe('normalizeHolidayListRow', () => {
    it('camelCase procId 应直接保留', () => {
      const row = normalizeHolidayListRow({ procId: 'PROC-001', id: 'ID-001' })
      expect(row.procId).toBe('PROC-001')
      expect(row.id).toBe('ID-001')
    })

    it('snake_case proc_id 应映射到 procId', () => {
      const row = normalizeHolidayListRow({ proc_id: 'PROC-SNAKE' })
      expect(row.procId).toBe('PROC-SNAKE')
    })

    it('字段优先级：procId > proc_id > processId > process_id > procInstId > proc_inst_id', () => {
      // 当多个候选字段同时存在时，取第一个有效值
      const row = normalizeHolidayListRow({
        procId: 'FIRST',
        proc_id: 'SECOND',
        processId: 'THIRD'
      })
      expect(row.procId).toBe('FIRST')  // 已有值不被覆盖
    })

    it('当 procId 为空时，应从其他候选字段填充', () => {
      const row = normalizeHolidayListRow({
        procId: '',  // 空串视为无效
        proc_id: 'FILL-ME'
      })
      expect(row.procId).toBe('FILL-ME')
    })

    it('holiday_id 应映射到 id', () => {
      const row = normalizeHolidayListRow({ holiday_id: 'HOLIDAY-001' })
      expect(row.id).toBe('HOLIDAY-001')
    })

    it('data_from 应映射到 dataFrom', () => {
      const row = normalizeHolidayListRow({ data_from: 'manual' })
      expect(row.dataFrom).toBe('manual')
    })

    it('空对象不应报错', () => {
      const row = normalizeHolidayListRow({})
      expect(row).toBeDefined()
    })
  })

  // ==================== normalizeHolidayReturnRow ====================
  describe('normalizeHolidayReturnRow', () => {

    describe('嵌套对象摊平', () => {
      it('应将 holiday 对象摊平到顶层', () => {
        const row = normalizeHolidayReturnRow({
          otherField: 'keep',
          holiday: { admissionNo: 'S001', type: '病假', reason: '感冒' }
        })
        expect(row.admissionNo).toBe('S001')
        expect(row.type).toBe('病假')
        expect(row.reason).toBe('感冒')
        expect(row.otherField).toBe('keep')
      })

      it('应依次尝试 RETURN_NESTED_KEYS 中的 key', () => {
        const keys = ['holiday', 'holidayInfo', 'isaHoliday',
                       'leaveHoliday', 'holidayVo', 'holidayEntity']

        for (const key of keys) {
          const raw = { [key]: { admissionNo: `TEST-${key}` } }
          const result = normalizeHolidayReturnRow(raw)
          expect(result.admissionNo).toBe(`TEST-${key}`)
        }
      })

      it('无嵌套对象时不应报错', () => {
        const result = normalizeHolidayReturnRow({ admissionNo: 'DIRECT' })
        expect(result.admissionNo).toBe('DIRECT')
      })
    })

    describe('学号字段归一化', () => {
      it.each([
        ['admissonNo', 'admissonNo'],
        ['admissionNo', 'admissionNo'],
        ['studentAdmissionNo', 'studentAdmissionNo'],
        ['student_admission_no', 'student_admission_no'],
        ['stuNo', 'stuNo']
      ])('应从 %s 取学号', (sourceKey) => {
        const result = normalizeHolidayReturnRow({ [sourceKey]: 'STU-123' })
        expect(result.admissonNo).toBe('STU-123')
      })
    })

    describe('类型字段归一化', () => {
      it.each([
        ['type', '事假'],
        ['holidayType', '病假'],
        ['leaveType', '年假']
      ])('应从 %s 取请假类型', (sourceKey, expected) => {
        const result = normalizeHolidayReturnRow({ [sourceKey]: expected })
        expect(result.type).toBe(expected)
      })
    })

    describe('scope 数组化', () => {
      it('逗号分隔字符串应拆分为数组', () => {
        const result = normalizeHolidayReturnRow({ scope: '周一,周二,周三' })
        expect(result.scope).toEqual(['周一', '周二', '周三'])
      })

      it('中文逗号也应拆分', () => {
        const result = normalizeHolidayReturnRow({ scope: '语文，数学，英语' })
        expect(result.scope).toEqual(['语文', '数学', '英语'])
      })

      it('数组应原样返回', () => {
        const arr = ['A', 'B'] as any
        const result = normalizeHolidayReturnRow({ scope: arr })
        expect(result.scope).toEqual(arr)
      })

      it('JSON 字符串数组应解析', () => {
        const result = normalizeHolidayReturnRow({ scope: '["X","Y"]' })
        expect(result.scope).toEqual(['X', 'Y'])
      })
    })

    describe('dateLimit 范围化', () => {
      it('"-" 连接符应拆分为数组', () => {
        const result = normalizeHolidayReturnRow({ dateLimit: '2024-01-01 ~ 2024-06-30' })
        expect(Array.isArray(result.dateLimit)).toBe(true)
      })

      it('数组应原样返回', () => {
        const arr = ['start', 'end'] as any
        const result = normalizeHolidayReturnRow({ dateLimit: arr })
        expect(result.dateLimit).toEqual(arr)
      })
    })
  })
})
```

```typescript
      })).toBe(false)
    })

    it('任一有效值应返回 true', () => {
      expect(hasActiveListFilters({ keyword: 'test' })).toBe(true)
      expect(hasActiveListFilters({ tags: ['a'] })).toBe(true)
    })
  })

  describe('useListTableEmpty', () => {
    const createWrapper = (filters?: Record<string, unknown>) => {
      return useListTableEmpty(ref(filters ?? {}))
    }

    it('初始状态应为 pending', () => {
      const { kind } = createWrapper()
      expect(kind.value).toBe('pending')
    })

    it('加载成功且 total=0 且无筛选 → no_data', async () => {
      const { kind, onLoadSuccess } = createWrapper({})
      onLoadSuccess({ total: 0, list: [] })
      await nextTick()
      expect(kind.value).toBe('no_data')
    })

    it('加载成功且 total>0 → has_data', async () => {
      const { kind, onLoadSuccess } = createWrapper({})
      onLoadSuccess({ total: 10, list: [{}] as any })
      await nextTick()
      expect(kind.value).toBe('has_data')
    })

    it('加载成功但 total=0 有筛选 → no_match', async () => {
      const { kind, onLoadSuccess } = createWrapper({ keyword: 'test' })
      onLoadSuccess({ total: 0, list: [] })
      await nextTick()
      expect(kind.value).toBe('no_match')
    })

    it('403 错误 → forbidden', async () => {
      const { kind, onRequestError } = createWrapper({})
      onRequestError({ response: { status: 403 } })
      await nextTick()
      expect(kind.value).toBe('forbidden')
    })

    it('网络错误 → network', async () => {
      const { kind, onRequestError } = createWrapper({})
      onRequestError({ response: { status: 500 } })
      await nextTick()
      expect(kind.value).toBe('network')
    })

    it('重试应调用 tableRef.refresh', () => {
      const refresh = vi.fn()
      const tableRef = ref<any>({ refresh })
      const { retry } = useListTableEmpty(ref({}), { tableRef })
      retry()
      expect(refresh).toHaveBeenCalled()
    })
  })
})
```
