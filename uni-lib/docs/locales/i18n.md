# I18n（vue-i18n 单一实例）

组件库通过 **`createUniLibI18n`** 创建 `vue-i18n` 实例（`globalInjection: true`，模板可用 `$t`，脚本可用 `useI18n({ useScope: 'global' })`），内置中英文文案已与 Element Plus 语言包在 **`UniConfigProvider`** 中对齐。

## 宿主接入步骤

1. **安装对等依赖**：`vue-i18n`（建议与宿主一致的大版本，例如 v11）。
2. **合并宿主文案**（同 key 时宿主覆盖库）：

```ts
import { createUniLibI18n } from "uni-ui-lib";

import en from "./locales/lang/en";
import zhCN from "./locales/lang/zh-CN";

export const i18n = createUniLibI18n({
  locale: "zh-CN",
  fallbackLocale: "zh-CN",
  hostMessages: {
    "zh-CN": zhCN as Record<string, unknown>,
    en: en as Record<string, unknown>,
  },
});
```

3. **`app.use(i18n)`**，且须在挂载业务树之前执行（通常在 Pinia 就绪之后）。
4. 根组件使用 **`UniConfigProvider`** 包裹路由视图，以便 Element Plus 分页、日期等内置文案随语言切换。

## Element Plus

`UniConfigProvider` 内部根据 **`useI18n({ useScope: 'global' }).locale`** 调用 `resolveElementPlusLocale`，将界面语言码映射为 Element Plus 的 `locale` 对象。

## 运行时追加文案

如需按需组装语言块，可使用库导出的 **`mergeDeep`** 合并后再调用 **`mergeLocaleMessage`**（或由宿主自选合并策略）。

## 组件库内部

- **`useUniI18n()`**：在 `<script setup>` 中使用全局 `useI18n`。
- **指令等非 setup 场景**：使用 **`uniLibTranslate`**（依赖 `createUniLibI18n` 注册的全局实例）。
