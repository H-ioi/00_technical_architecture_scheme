# 迭代-20260511

> **命名规则**：迭代说明使用 `迭代-[当天日期].md`（例：`迭代-20250511.md`）。**同一天内**的多次调整合并写在**同一个**文档中，用下方小节区分。

## 校车学生表单：审批状态切换误触发表单校验

- **现象**：申请意向、乘车学生共用的「新增/编辑」弹窗中，切换「审批状态」会在未点击确定时，对校区、学期、学号、接送方式等其它必填项展示校验错误。
- **原因**：`mainRules` 随 `approvalStatus` / 缴费联动变化，`el-form` 默认 `validateOnRuleChange` 为 `true`，rules 引用更新后会触发整表校验。
- **修改**：在 `bus-order-form-dialog.vue` 的 `mainFormConfig.formProps` 中设置 `validateOnRuleChange: false`，保留各字段自有 `trigger`（blur/change）及提交时 `validate()` 行为。

## 编辑弹窗：详情接口慢时增加表单区 loading

- **需求**：接口响应慢时，弹窗已打开但表单空白或旧数据闪一下；希望在拉取详情完成前显示加载态。
- **实现**：
  - 新增 `admin-web/src/composables/use-dialog-detail-loading.ts`：`detailLoading` + `runWithDetailLoading`，配合 `v-loading` 与 `common.loading` 文案。
  - 在 `common` 中英文案增加 `loading`。
  - 已对以下「打开后异步拉详情」的弹窗/表单区接入：`bus-order-form-dialog`（编辑）、司机/车辆/跟车老师/路线运营/路线异常表单、协议编辑与协议详情抽屉、学期/站点编辑弹窗、路线规划 `route-form-modal` 编辑态。
- **约定**：后续新增同类弹窗可在异步 `detail/get` 外包一层 `runWithDetailLoading`，并在 `UniForm` 外包一层带 `v-loading` 的容器。

## uni-lib UniLayout 侧栏菜单支持纵向滚动

- **问题**：侧栏 `overflow: hidden`，菜单随层级展开超出视口后被裁切，无滚动条。
- **修改**：`uni-layout/index.vue` 中侧栏改为纵向 flex（Logo 固定高度、`flex-shrink: 0`）；`el-menu` 外包一层 `uni-layout__menu-wrap`，设置 `flex: 1`、`min-height: 0`、`overflow-y: auto`，使菜单在 Logo 下方区域内独立滚动。

## uni-lib：`route.meta` 首帧 undefined 导致白屏

- **现象**：admin-web 切本地 `uni-lib` 后启动报错 `Cannot read properties of undefined (reading 'meta')`，栈在 UniLayout 的 computed。
- **原因**：写成 `route.meta?.xxx` 时，`route` 为 `undefined` 仍会先访问 `.meta` 再短路；在 `app.use(router)` 与首屏渲染交界，本地链接/多实例时偶发 `useRoute()` 尚未就绪。
- **修改**：`uni-layout/index.vue`、`tags-view.vue` 中凡读当前路由统一改为 `route?.fullPath`、`route?.meta?....`、`route?.matched`，并在同步标签处对 `matched` 做空数组保护。

## admin-web：本地 uni-lib rebuild 后仍像旧版本

- **原因**：Vite 会把依赖预构建到 `node_modules/.vite/deps/`；`uni-ui-lib` 走 `file:../uni-lib` 且入口为 `dist/index.mjs` 时，仍可能被缓存，重启 dev 仍命中旧 chunk。
- **修改**：`admin-web/vite.config.ts` 增加 `optimizeDeps.exclude: ['uni-ui-lib']`，开发时直接解析库产物、减少过时预构建；`resolve.dedupe` 增加 `vue`、`vue-router`，降低本地链接多实例风险。
- **脚本**：`package.json` 增加 `dev:force`（`vite --force`）、`cache:clean:vite`（删除 `node_modules/.vite`），可在仍异常时强制清 Vite 缓存。
- **其它**：若包管理器把 `file:` 装成拷贝而非 symlink，需在 uni-lib `build` 后于 admin-web 目录再执行一次安装以更新 `node_modules/uni-ui-lib`。

## 菜单编辑：上级菜单 `-1` 显示为「根节点」

- **原因**：接口可能返回字符串 `parentId: "-1"`，下拉里根节点选项的 `value` 为数字 `-1`，`el-select` 严格相等匹配不到选项，折叠态会显示原始 `-1`。
- **修改**：`use-list.ts` 增加 `normalizeParentIdForSelect`，在 `openEdit` 与提交 `payload` 中将 `undefined` / `null` / `''` / `-1` / `"-1"` 统一为数字 `-1`，与 `permission.menu.rootParent`（根节点）选项一致。
