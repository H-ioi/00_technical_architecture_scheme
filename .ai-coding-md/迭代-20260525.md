## 核心逻辑变更

1. 组件库提供统一的 `registerServiceWorker`，负责 SW 注册回调与顶部更新提示 UI。
2. admin-web 通过 `vite-plugin-pwa` 生成 SW 与 manifest，生产环境动态加载 `virtual:pwa-register` 并交给组件库处理。
3. 开发环境默认不注册 SW（`vite-plugin-pwa` 的 dev 版 `registerSW` 为空实现）；需联调时在 `.env.development` 设置 `VITE_PWA_DEV=true` 并重启 dev server，或执行 `npm run build && npm run preview` 验证。

## 注意事项

- 构建前需先 `npm run build --prefix ../uni-lib`，admin-web 依赖本地 `file:../uni-lib`。
- 发布 uni-lib 新版本后，admin-web 可改回 npm 版本号。
- PWA 默认仅在 `npm run build` 后的生产产物中生效；`npm run preview` 或 `VITE_PWA_DEV=true` 可用于本地验证。
