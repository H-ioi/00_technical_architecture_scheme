### 核心逻辑变更点

### 注意事项

- `logo.svg` 已替换为纯矢量 SVG（见下文）。

## uni-lib：UniLogo 改为纯矢量 SVG

### 修改文件

- `uni-lib/src/icons/svg/logo.svg`
- `uni-lib/src/icons/generated/UniLogo.vue`（重新生成）

### 核心逻辑变更点

1. **根因**：旧 `logo.svg` 内嵌 PNG 位图，颜色固定，无法随 `--uni-layout-brand-color` 切换。
2. **处理**：基于 `logo-j.png` 图标区轮廓矢量化，拆为 I / S / A 三段 `<path>`，`fill="currentColor"`。
3. **效果**：包体由 ~274KB 降至 ~3KB；ISA / EMS / MAS 布局下 Logo 可随主题色变化。

### 注意事项

- 若品牌 Logo 造型更新，请替换 `src/icons/svg/logo.svg` 后执行 `npm run icons:generate`。

## uni-lib：UniLogo 去除锯齿，改为平滑几何矢量

### 修改文件

- `uni-lib/src/icons/svg/logo.svg`
- `uni-lib/src/icons/generated/UniLogo.vue`（重新生成）

### 核心逻辑变更点

1. **根因**：上一版由 50×45 像素轮廓逐步追踪，path 全是 1px 阶梯线段，放大后锯齿明显。
2. **处理**：改为手绘几何：`I` 用 `<rect>`，`A` 用梯形 `<path>`，`S` 用三次贝塞尔曲线；并加 `shape-rendering="geometricPrecision"`。

### 注意事项

- 若 S 曲线与品牌稿仍有偏差，请在设计稿基础上微调 `logo.svg` 中 S 的 `d` 属性。

## uni-lib：UniLogo 按参考稿修正形状

### 修改文件

- `uni-lib/src/icons/svg/logo.svg`
- `uni-lib/src/icons/generated/UniLogo.vue`（重新生成）

### 核心逻辑变更点

1. **根因**：手绘贝塞尔与像素简化均与品牌稿 `Horizontal purple@3x` 偏差较大，S 形尤其变形。
2. **处理**：按参考 PNG 精确测量 I / S / A 外轮廓比例重写：`I` 矩形、`A` 梯形、`S` 按外边界关键点折线描边；`viewBox="0 0 1024 919"` 与参考稿一致。
3. **效果**：保留 `currentColor` 主题染色，边缘平滑且造型对齐参考稿。

## uni-lib：UniLogo S 形双弧改为贝塞尔曲线

### 修改文件

- `uni-lib/src/icons/svg/logo.svg`

### 核心逻辑变更点

## uni-lib：UniLogo 直接由品牌 PNG 追踪为纯矢量

### 修改文件

- `uni-lib/src/icons/svg/logo-source.png`（品牌稿 `Horizontal purple@3x`）
- `uni-lib/src/icons/svg/logo.svg`
- `uni-lib/scripts/trace-logo-from-png.py`
- `uni-lib/src/icons/svg/README.md`
- `uni-lib/src/icons/generated/UniLogo.vue`（重新生成）

### 核心逻辑变更点

1. **根因**：手绘/近似贝塞尔仍与品牌稿偏差，用户要求直接使用提供的 PNG。
2. **处理**：从 `logo-source.png` 提取 I / S / A 三块轮廓；I 用矩形、A 用梯形、S 用边界点 Catmull-Rom 转 `C` 曲线；`fill="currentColor"`。
3. **再生**：`python scripts/trace-logo-from-png.py` → `npm run icons:generate`。
