## uni-lib：侧栏 Logo 改为 UniLogo + 名称 + 描述

### 修改文件

- `uni-lib/src/components/uni-layout/components/sidebar.vue`
- `uni-lib/src/components/uni-layout/index.vue`
- `uni-lib/src/styles/components.scss`
- `uni-lib/src/styles/variables.scss`

### 核心逻辑变更点

1. **侧栏品牌区**：默认由 `<img>` 改为 `UniLogo` + 名称 + 描述；折叠菜单时仅保留图标。
2. **框架布局联动**：根据 `frameworkLayout` / `preset` 自动切换默认文案：
   - `isa-light`：ISA SMS / 爱莎学校运营管理系统（深色字）
   - `ems-dark`：EMS / 教学业务管理系统（金色字）
   - `mas-dark`：MAS / 市场招生管理系统（金色字）
3. **可覆盖**：`UniLayout` 新增 `brandName`、`brandDescription` 可选 props；`#logo` 插槽仍可完全自定义。
4. **样式 token**：各 layout 增加 `--uni-layout-brand-color` 控制 Logo 与文字颜色。

### 注意事项

- 已移除 `UniLayout` 的 `logo` / `logoAlt` props；若业务需自定义图片 Logo，请使用 `#logo` 插槽。
- 主题设置中切换「框架布局」后，侧栏品牌文案与配色会同步更新。

## uni-lib：修复 UniLogo 生成后显示为色块

### 修改文件

- `uni-lib/scripts/generate-icons.mjs`
- `uni-lib/src/icons/generated/UniLogo.vue`（重新生成）
- `uni-lib/src/icons/svg/README.md`

### 核心逻辑变更点

1. **根因**：`logo.svg` 为内嵌 PNG + `fill="url(#pattern_0)"`；`icons:generate` 默认把非 `currentColor` 的 fill 全替换成 `currentColor`，图案引用丢失，矩形变成纯色块。
2. **修复**：生成脚本保留 `fill/stroke="url(...)"` 引用；重新执行 `npm run icons:generate`。

### 注意事项

- `logo.svg` 已替换为纯矢量 SVG（见下文）。

## uni-lib：UniLogo 改为纯矢量 SVG

### 修改文件

- `uni-lib/src/icons/svg/logo.svg`
- `uni-lib/src/icons/generated/UniLogo.vue`（重新生成）

### 核心逻辑变更点

1. **根因**：旧 `logo.svg` 内嵌 PNG 位图，颜色固定，无法随 `--uni-layout-brand-color` 切换。
2. **处理**：基于 `logo-j.png` 图标区轮廓矢量化，拆为 I / S / A 三段 `<path>`，`fill="currentColor"`。
3. **效果**：包体由 ~274KB 降至 ~3KB；ISA / EMS / MAS 布局下 Logo 可随主题色变化。

### 注意事项

- 若品牌 Logo 造型更新，请替换 `src/icons/svg/logo.svg` 后执行 `npm run icons:generate`。

## uni-lib：UniLogo 去除锯齿，改为平滑几何矢量

### 修改文件

- `uni-lib/src/icons/svg/logo.svg`
- `uni-lib/src/icons/generated/UniLogo.vue`（重新生成）

### 核心逻辑变更点

1. **根因**：上一版由 50×45 像素轮廓逐步追踪，path 全是 1px 阶梯线段，放大后锯齿明显。
2. **处理**：改为手绘几何：`I` 用 `<rect>`，`A` 用梯形 `<path>`，`S` 用三次贝塞尔曲线；并加 `shape-rendering="geometricPrecision"`。

### 注意事项

- 若 S 曲线与品牌稿仍有偏差，请在设计稿基础上微调 `logo.svg` 中 S 的 `d` 属性。
