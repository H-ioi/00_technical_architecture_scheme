# 迭代-20260518

## uni-search-form 样式在 admin-web 中不生效（排查结论）

**说明**：`scoped` 本身没有问题。业务侧正常引入同一版本的 `uni-ui-lib`（`dist/index.mjs` + `uni-ui-lib/style.css` / `index.css`）时，`data-v-*` 与样式选择器一致，可以正常加载。

**异常场景**：若联调时出现「组件 JS 与全局 CSS 不是同一次构建」（例如 link、`file:`、未 rebuild、或 Vite 依赖缓存混用），会出现 DOM 上的 `data-v-*` 与 `index.css` 里不一致，表现为组件样式「像没加载」。

**联调习惯**：改 `uni-lib` 后执行 `yarn uni-lib:build`（或 `uni-lib` 内 `npm run build`），必要时 `vite --force`。

## uni-lib 组件样式去掉 scoped

**范围**：`uni-lib/src` 下全部 Vue 组件的 `<style scoped>` 改为非 scoped；原 `:deep(...)` 改为在对应根类（如 `.uni-data-table`、`.uni-theme-settings`、`.uni-layout-tags`）下嵌套的普通选择器。

**目的**：打包后的 `dist/index.css` 不再依赖 `data-v-*`，业务侧 JS/CSS 不同步时布局类样式仍可命中。

**说明**：`uni-layout/index.vue` 中原先用于 Teleport 下拉的第二个 `<style lang="scss">`（`.uni-layout-user-dropdown`）保持不变。
