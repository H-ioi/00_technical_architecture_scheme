# 迭代-20260518

## uni-search-form 样式在 admin-web 中不生效

**原因**：`UniSearchForm` 使用 `scoped` 样式时，运行时 DOM 上的 `data-v-*` 必须与 `uni-ui-lib/style.css`（即 dist `index.css`）里选择器上的哈希一致。若业务端 JS 来自一次编译（例如本地链到 `uni-lib` 源码由 Vite 再编译）、而 CSS 仍指向 npm 里另一版 dist，则哈希不一致，DevTools 中看不到对应规则。

**处理**：去掉 `uni-search-form/index.vue` 的 `scoped`，仅用 `.uni-search-form` BEM 前缀限定作用域；嵌套的 `.el-form-item` 替代原 `:deep(.el-form-item)`。

**联调**：修改组件库后需执行 `admin-web` 下 `yarn uni-lib:build`（或 `uni-lib` 内 `npm run build`），必要时 `vite --force` 清依赖缓存。
