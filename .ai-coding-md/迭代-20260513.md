# 迭代-20260513

## defineModel 全局迁移（uni-lib + admin-web）

### 背景

将双绑显式写法（`:model-value` + `emit('update:…')` 或 `computed` get/set）替换为 Vue 3.4+ 的 `defineModel`，减少样板代码与事件名笔误。

### uni-lib

- **uni-form**：默认模型 `defineModel<Recordable>`，移除 `localModel` + 对 `props.modelValue` 的深度 watch，直接以 `model` 驱动表单与回写。
- **uni-search-form**：`defineModel<Recordable>({ required: true })`，内部 `UniForm` 使用 `v-model="model"`。
- **uni-upload**：`defineModel('fileList')`，移除手写 `update:fileList` emit。
- **uni-theme-settings / change-password-dialog**：可见性用 `defineModel<boolean>`。
- **security-verify-dialog**：`defineModel('visible')`，与父级 `v-model:visible` 对齐。
- **toolbar**：`fullscreen` / `stripe` / `border` 三个命名 `defineModel`，与数据表 `v-model:*` 一致。

### admin-web

- 各类 **Dialog / Drawer**（协议、权限、校车、考勤详情等）：`defineModel('visible')` 或与 Element 默认 `modelValue` 对齐的 `defineModel` / `defineModel('visible')`。
- **学期/站点弹窗**：`defineModel<boolean>()` 作为默认 `v-model`（`modelValue`）。
- **校车订单弹窗**：`defineModel('visible')`，去掉中间 `computed` 桥。
- **IconPicker**：`defineModel<string>`。
- **类型文件**：`ProtocolFormProps`、`ProtocolPanelProps`、`MemberDetailProps`、`SchoolBusDriverFormProps` 等去掉 `visible` / `update:visible`，由 `defineModel` 承担。

### 其它

- 删除 `attendance/holiday/list.config.ts` 中未使用的 `pickFirstLoose`、销假展示辅助函数（原无引用，仅消除 ESLint 报错）。

- `uni-lib`: `npm run type-check` 通过。
- `admin-web`: `npm run type-check` 通过。

### UniForm 调用方统一 `v-model`（与 defineModel 对齐）

- 新增 `composables/use-view-only-form-model.ts`：查看态下父级传入的 `source` 仍是 prop，不能直接向子组件 `v-model` 绑定 prop；用「只读计算属性 + 空 setter」包一层，再 `v-model` 给 `UniForm`。
- 已替换：**考勤** access/school/student/wechat/wechat-notice 详情弹窗、**holiday** 详情抽屉、**member** 详情、`protocol/detail` 页（`viewModel` computed 增加空 `set`）。

### 去除模板中 `:model-value` 残留（EP / UniForm 内部）

- **uni-form**：Vue 编译器要求 `v-model` 只能是**成员表达式**（如 `a.b`、`ref`），**不能**使用 `v-model="fieldVm(field)"` 这类函数调用，否则生产构建报错；动态字段仍用 `:model-value` + `@update:model-value` 汇总到 `handleFieldChange`。**UniUpload** 继续 `:file-list` + `@update:file-list`。
- **uni-data-table/cell.vue**：开关列改为 `v-model="switchModel"`。
- **icon-picker**：只读输入改为 `v-model="model"`。

### UniSearchForm `reduce` 运行时错误（配置 / 放行条 / 流程定义）

- **现象**：进入 `/attendance/holiday/config` 等页控制台报 `Cannot read properties of undefined (reading 'reduce')`，栈在 `uni-search-form` 内对 `config.schema` 的计算。
- **原因**：`UniSearchForm` 的 `config` 必须为 `UniFormConfig`（含 `schema: UniFormField[]`）。若传入旧版「检索字段数组」或缺少 `schema`，则 `props.config.schema` 为 `undefined`，`reduce` 抛错（与此前请假 Tab 重构时问题同类）。
- **修复**：`config/list.config.ts`、`pass/list.config.ts` 的检索工厂改为返回 `{ schema: [...] }`（字段使用 `ElSelect` / `ElInput`、`componentProps`、`colProps`，与 `attendanceHolidaySearchForm` 一致）；`flow/components/flow-def-panel.vue` 的 `searchCfg` 由 `UniSearchFieldConfig[]` 改为 `computed<UniFormConfig>`。

### 新增子模块表格列不显示 / vnode 报错（列定义 API 误用）

- **现象**：配置管理、放行条、流程定义/部署、任务待办/已办等页表头或表体异常、控制台 `vnode` / `parentNode` 相关错误。
- **原因**：`UniDataTable` 的列类型为 `UniTableColumn`，必须使用 **`prop`、`label`、`formatter`**（见请假主列表 `list.config.ts`）。误用 **`field`、`labelKey`、`format`** 时，`prop` 为 `undefined`，表格列 `:key` 与列设置状态错乱，导致渲染与卸载异常；`label` 为空则表头异常。
- **修复**：上述页面的列定义全部改为 `UniTableColumn[]`，`label` 用 `t('...')` 预翻译；自定义列用标准 `formatter`。误写的类型名 `UniTableColumnConfig` 改为 **`UniTableColumn`**（库内无前者导出，且与真实契约不一致）。

## 接口响应信封 / 分页：全局归一化 `api-response-normalize`

### 背景

各模块接口返回结构不一致（Spring `records`/`total`、`totalCount`+`list`、顶层 `data` 数组、嵌套 `data.records`、群发邮件 `totalCount` 等），原在各 `use-list`、弹窗内重复 `unwrap*` 函数。

### 实现

- 新增 **`admin-web/src/utils/api-response-normalize.ts`**：注释约定「仅封装当前仍混用的形状」，新接口宜在后端或 HTTP 封装层统一。
- **`normalizePaged`**：分页列表 → `{ list, total }`。
- **`normalizeEnvelope`**：单层 `{ data: 对象 }` 脱信封；否则顶层对象。
- **`normalizePayload`**：会员 / 检索类，兼容双层 `{ data: { data } }` 与单层 `data`。
- **`normalizeArray`**：只取数组（配置列表、下拉、校车 `sectionList` 等），**不再**回退调用分页拆解。
- **`normalizeSchoolBusDetail`**：校车详情 `{ success, data }` / 实体识别字段，与原 `unwrapLineDetail`、站点/学期弹窗一致。

### 精简（减少兜底解析）

- **`normalizePaged`**：去掉「根为纯数组」「仅有 total、列表为空」等少用兜底。
- **`normalizeArray`**：去掉末尾对 **`normalizePaged`** 的调用。
- 详情与 **`normalizeEnvelope`** 重复的 **`normalizeApiDetailBody`** 已删除，下单详情等处直接用 **`normalizeEnvelope`**。

### 迁移

- 删除 **`views/email/mail-page-utils.ts`** 中的分页与信封解包，保留 **`formatMailGroupScopeDisplay`**；邮件列表与弹窗改引用 **`@/utils/api-response-normalize`**。
- 删除 **`holiday-utils.ts`** 中的 **`unwrapHolidayPage` / `unwrapDetailPayload`**（请假/销假/放行条等改用公共方法）。
- 考勤、权限、校车、流程 Tab、任务待办等列表与表单中的本地 **`unwrapPage` / `unwrapArray` / `unwrapDetail`** 等替换为上述方法。

### 验证

- `admin-web`：`npm run type-check` 通过。

### 导出命名（简短一致）
