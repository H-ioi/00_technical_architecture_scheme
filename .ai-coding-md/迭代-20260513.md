# 迭代-20260513

## defineModel 全局迁移（uni-lib + admin-web）

### 背景

将双绑显式写法（`:model-value` + `emit('update:…')` 或 `computed` get/set）替换为 Vue 3.4+ 的 `defineModel`，减少样板代码与事件名笔误。

### uni-lib

- **uni-form**：默认模型 `defineModel<Recordable>`，移除 `localModel` + 对 `props.modelValue` 的深度 watch，直接以 `model` 驱动表单与回写。
- **uni-search-form**：`defineModel<Recordable>({ required: true })`，内部 `UniForm` 使用 `v-model="model"`。
- **uni-upload**：`defineModel('fileList')`，移除手写 `update:fileList` emit。
- **uni-theme-settings / change-password-dialog**：可见性用 `defineModel<boolean>`。
- **security-verify-dialog**：`defineModel('visible')`，与父级 `v-model:visible` 对齐。
- **toolbar**：`fullscreen` / `stripe` / `border` 三个命名 `defineModel`，与数据表 `v-model:*` 一致。

### admin-web

- 各类 **Dialog / Drawer**（协议、权限、校车、考勤详情等）：`defineModel('visible')` 或与 Element 默认 `modelValue` 对齐的 `defineModel` / `defineModel('visible')`。
- **学期/站点弹窗**：`defineModel<boolean>()` 作为默认 `v-model`（`modelValue`）。
- **校车订单弹窗**：`defineModel('visible')`，去掉中间 `computed` 桥。
- **IconPicker**：`defineModel<string>`。
- **类型文件**：`ProtocolFormProps`、`ProtocolPanelProps`、`MemberDetailProps`、`SchoolBusDriverFormProps` 等去掉 `visible` / `update:visible`，由 `defineModel` 承担。

### 其它

- 删除 `attendance/holiday/list.config.ts` 中未使用的 `pickFirstLoose`、销假展示辅助函数（原无引用，仅消除 ESLint 报错）。

### 验证

- `uni-lib`: `npm run type-check` 通过。
- `admin-web`: `npm run type-check` 通过。

### UniForm 调用方统一 `v-model`（与 defineModel 对齐）

- 新增 `composables/use-view-only-form-model.ts`：查看态下父级传入的 `source` 仍是 prop，不能直接向子组件 `v-model` 绑定 prop；用「只读计算属性 + 空 setter」包一层，再 `v-model` 给 `UniForm`。
- 已替换：**考勤** access/school/student/wechat/wechat-notice 详情弹窗、**holiday** 详情抽屉、**member** 详情、`protocol/detail` 页（`viewModel` computed 增加空 `set`）。

### 去除模板中 `:model-value` 残留（EP / UniForm 内部）

- **uni-form**：动态字段对 Element 组件改为 `v-model="fieldVm(field)"`（缓存 writable computed，写入仍走 `handleFieldChange`；`schema` 变更清空缓存）。**UniUpload** 保持 `:file-list` + `@update:file-list`，避免 `v-model:file-list` 与 `WritableComputedRef` 的类型推导问题。
- **uni-data-table/cell.vue**：开关列改为 `v-model="switchModel"`。
- **icon-picker**：只读输入改为 `v-model="model"`。
