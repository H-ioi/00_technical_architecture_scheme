- 多业务列表接入 `#empty`、`@request-error` 与合并后的 `@load-success`。

### 2. 超长表单（校车订单弹窗）

- `bus-order-form-dialog.vue`：关闭前未保存二次确认（baseline JSON）、提交成功跳过确认；校验失败 `scrollToField` 及部分业务区滚动锚点。

### 3. 校车学生列表多级联动筛选

- `use-student-order-filters`：加载态、失败重试、`StudentOrderSearchCascade`；申请单/订单 list 配置禁用与 loading；页面 `el-alert` 提示与重试。

### 4. 路线规划导入导出反馈

- `route/plan/tab.vue`：导入全屏 `ElLoading`；`summarizeImportRows` 区分服务端文案与行级错误；有错误行时支持弹窗内「下载错误明细」（完整失败列表为 txt）。
- 文案：`schoolBus.importProgress`、`importHadRowErrors`、`downloadErrorReport`（zh/en）。

### 5. 可选：Tab 与 URL 同步

- 新增 `composables/use-tab-query-sync.ts`，默认同步 query `tab`。
- 接入：`school-bus/route/plan/tab.vue`（routes | term | station）、`attendance/holiday/tab.vue`（leave | return）、`email/outbox/tab.vue`（sent | draft），支持刷新恢复与分享带 Tab 的链接。

### 6. 校车申请/订单表单：主容器改为抽屉；审批与缴费状态同一行

- `bus-order-form-dialog.vue`：`el-dialog` 改为右侧 `el-drawer`（宽约 1000px，`min(1000px, 96vw)`）；抽屉 body 纵向 flex，滚动区在表单内容区；路线/接送人子弹窗仍为 `el-dialog` 且 `append-to-body`。
- 审批状态与缴费状态合并为 `approvalPaymentRowSlot`：`el-row` 两列（同意审批时显示缴费列，否则审批占满行）；标签用既有 `bus-order-form__nested-label` 样式。

### 7. Element Plus 数字输入：`controls-position="right"`（已迁至 uni-lib，见 §9）

### 8. 校车订单抽屉：说明顶部「跳转」、消除横向滚动条

- `bus-order-form-dialog.vue`：顶部为 **锚点跳转**（非路由 Tab）；补充「基础」一键滚回表单顶；Vue 注释标注意图。
- 横向滚动：`el-drawer` body 与表单滚动区 `overflow-x: hidden`；路线/接送人表 **`fixed="right"` 操作列** 易撑出整块横向滚动条，改为普通列并给表格外层 `table-wrap` 约束宽度；审批/缴费行由 `el-row` gutter 改为 **flex + gap**，减少 `el-row` 负外边距溢出。

### 9. uni-lib：`install` 内注入 `ElInputNumber` 默认值；admin-web 入口减负

- `uni-lib/src/plugins/install.ts`：在注册组件逻辑之前执行 `ElInputNumber.setPropsDefaults({ controlsPosition: 'right' })`（peer：`element-plus`）。
- `uni-lib/src/types/uni-install.ts`：新增可选 `applyElementPlusPropDefaults`，传 `false` 可关闭此项，由业务自行配置。
- `admin-web/src/main.ts`：移除入口处的 `setPropsDefaults`；将 `initUniLib(app)` **提前到** `app.use(ElementPlus)` 之前，与同库原先的「先于 EP 挂载设默认」顺序一致。**发布链路**：改动需 `npm run build --prefix uni-lib` 并升级/替换 admin-web 所依赖的 `uni-ui-lib` 包后方可生效。
