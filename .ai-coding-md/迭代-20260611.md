## 接入 Playwright E2E

### 修改文件

- `admin-web/package.json`（`@playwright/test`；脚本 `test:e2e` / `test:e2e:ui` / `test:e2e:report`）
- `admin-web/playwright.config.ts`（新建）
- `admin-web/e2e/auth.setup.ts`、`e2e/smoke.spec.ts`、`e2e/shell.spec.ts`、`e2e/helpers/auth.ts`（新建）
- `admin-web/.env.e2e.example`（新建）
- `admin-web/.gitignore`（忽略 `e2e/.auth/`、playwright 报告目录）

### 核心逻辑变更点

- **三层 project**：`setup`（OAuth 写 storageState）→ `smoke`（免登录）→ `chromium`（需 `E2E_USERNAME` / `E2E_PASSWORD`）。
- **登录绕过滑块**：`e2e/helpers/auth.ts` 与 `auth.ts` 同算法直连 `/api/auth/oauth/token`。
- **smoke**：登录页渲染、未登录访问业务 URL 重定向登录。
- **shell**：dashboard、404、attendance holiday 书签、问卷 design→edit 重定向（需真实账号 + 后端）。

### 注意事项

- 首次运行：`npx playwright install chromium`（已执行一次即可）。
- 无账号时仅 `smoke` 通过；配置 `.env.e2e.local` 后 `shell` 才执行。
- 登录含滑块验证码，首次 setup 约 1～5 分钟；`e2e/.auth/user.json` 4 小时内复用。强制重登：`E2E_FORCE_LOGIN=true`。
- 旧 isacommunity 书签直链尚未在 router 注册，**未**纳入 E2E（仅测 router 内已有 redirect）。
