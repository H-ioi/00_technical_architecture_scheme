## uni-lib：统一动效 token 与基础过渡

### 修改文件

- `uni-lib/src/styles/variables.scss`
- `uni-lib/src/styles/base.scss`
- `uni-lib/src/styles/components.scss`
- `uni-lib/src/components/uni-layout/components/tags.vue`

- `uni-lib/src/components/uni-data-table/components/toolbar.vue`

### 核心逻辑变更点

1. **Motion token**：在 `:root` 增加 `--uni-duration-*`、`--uni-ease-*` 及 `--uni-transition-colors/layout/opacity/transform/tag-close` 等组合变量，供全局与组件引用。
2. **无障碍**：`base.scss` 增加 `prefers-reduced-motion: reduce` 兜底，系统开启减少动效时压缩 animation/transition 时长。
3. **现有动效对齐 token**：layout sidebar/header、tags 关闭按钮、验证码滑块、PWA 卡片等硬编码 `0.2s ease` 改为 CSS 变量。
4. **复用过渡类**：`components.scss` 新增 `.uni-fade-*`（Vue `<Transition name="uni-fade">`）；`uni-search-form` 已选标签区使用该过渡。
5. **微交互补充**：layout 菜单项、表格 toolbar 按钮、搜索表单收起链接触发 `--uni-transition-colors`。

### 注意事项

- Dialog / Drawer / Popover 等仍依赖 Element Plus 内置进出场，未重复封装。
- PWA 注入样式通过 `var(--uni-*)` 读取 token，需确保页面已加载 uni-lib 样式。
- 业务页新增动效应优先引用 `--uni-transition-*`，避免再写裸 duration/easing。

## admin-web：修复 UniForm v-model 与 reactive 编译告警

### 修改文件

- `admin-web/src/views/permission/role/list.vue`
- `admin-web/src/views/attendance/holiday/components/holiday-form-drawer.vue`
- `admin-web/src/views/attendance/pass/components/pass-form-dialog.vue`
- `admin-web/src/views/activity/questionnaire/components/copy-dialog.vue`
- `admin-web/src/views/activity/questionnaire/components/batch-flag-dialog.vue`
- `admin-web/src/views/activity/questionnaire/components/meta-form-dialog.vue`
- `admin-web/src/views/activity/program/components/program-copy-dialog.vue`

### 核心逻辑变更点

1. **根因**：`UniForm` 的 `v-model` 会整体替换 model 对象，不能直接绑在 `const form = reactive(...)` 上，否则触发 `[@vue/compiler-sfc]` 告警。
2. **修复**：沿用项目既有写法（如活动报名编辑弹窗），增加 `formModel` / `roleFormModel` 计算属性，`get` 返回 reactive 对象，`set` 用 `Object.assign` 合并更新，模板改绑计算属性。

### 注意事项

- 业务逻辑仍读写原 `form` / `roleForm` reactive 对象，无需改提交与校验代码。
- 新建 `UniForm v-model` 时优先 `ref` 或上述 computed 桥接，避免 `const reactive` 直绑。
