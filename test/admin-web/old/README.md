#### 目录结构
```
├─.browserslistrc               
├─.editorconfig                 
├─.eslintignore
├─.eslintrc.js --------------------------------------------- eslintrc
├─.postcssrc.js
├─babel.config.js
├─debug.log ------------------------------------------------ 报错日志
├─package-lock.json             
├─package.json   ------------------------------------------- package.json               
├─vue.config.js -------------------------------------------- Vue项目配置文件                    
├─src                               
|  ├─App.vue                    
|  ├─cache.js  --------------------------------------------- 缓存                 
|  ├─error.js  --------------------------------------------- 错误                 
|  ├─main.js ----------------------------------------------- 入口文件                   
|  ├─permission.js ----------------------------------------- 权限                 
|  ├─api --------------------------------------------------- 接口请求api                     
|  ├─views ------------------------------------------------- 业务Vue文件                     
|  ├─util--------------------------------------------------- 方法封装                   
|  ├─styles ------------------------------------------------ CSS文件                    
|  ├─store ------------------------------------------------- VueX文件                
|  ├─router ------------------------------------------------ 路由配置                       
|  ├─page  ------------------------------------------------- 其他Vue文件                     
|  ├─mixins------------------------------------------------- mixins方法封装                   
|  ├─i18n -------------------------------------------------- 国际化                      
|  ├─filters ----------------------------------------------- Vue过滤器                   
|  ├─const ------------------------------------------------- 业务数据                 
|  ├─config ------------------------------------------------ 配置文件               
|  ├─components--------------------------------------------- 自定义组件                     
├─public---------------------------------------------------- 静态文件
```
#### 运行指令
```
初始化指令：npm install;
运行指令：
npm run dev----------------------------本地开发环境;
npm run test----------------------------演示环境;
npm run product----------------------------正式环境;
打包指令：
npm run test-build------------------------------演示环境;
npm run build------------------------------正式环境;
```
