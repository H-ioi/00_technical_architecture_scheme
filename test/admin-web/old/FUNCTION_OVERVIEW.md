# Project Function Overview（现有功能梳理）

> 说明：本清单基于项目路由配置（`src/router`）和入口页面/功能块命名进行归纳，覆盖“系统能做什么”的全景地图。由于页面/组件数量很多，未逐一列出每个子组件与每条 API；如需“某一模块的页面-接口-验收点”逐项清单，可以再按模块展开。

---

## 1. 全站基础能力（贯穿所有业务）

1. 多系统/多入口登录
  - `/login`：MOS 登录页
  - `/loginisa`：The Pool 登录页
  - `/logingroup`：数据平台登录页
  - `/loginisacentre`：科城中心登录页
  - `/isacommunity/login`：爱莎圈登录页
  - `/ems/login`：EMS 教学业务管理系统登录页
2. 权限控制与路由拦截
  - 路由守卫在 `src/permission.js`
  - 未登录态（`store.getters.access_token` 为空）时，会重定向到对应登录入口
  - 白名单通常包含：`/login`、`/lock`、`/redirect`、`/401`、`/403`、`/404`
3. 锁屏与错误页
  - `/lock`：锁屏页
  - `/401`、`/403`、`/404`、`/500`：错误页
4. 国际化
  - `src/i18n` + `vue-i18n`，页面大量使用 `$t('...')`
5. 路由加载进度条
  - `nprogress`：路由切换时的加载反馈

## 3. 公共功能能力（跨业务被多次复用）

1. 图表可视化
  - `echarts`、`echarts-liquidfill`
2. 日历交互
  - `@fullcalendar/*`（包含 daygrid/timegrid/interaction）
3. 富文本/编辑器
  - `tinymce`（以及 `@tinymce/tinymce-vue`）
  - `vue-quill-editor`（Quill）
  - WangEditor（`@wangeditor/editor` + `@wangeditor/editor-for-vue`）
4. 流程图/流程建模
  - `bpmn-js`
  - `bpmn-js-properties-panel`
  - `camunda-bpmn-moddle`
5. 地区/国家数据与字典
  - `china-area-data`、`element-china-area-data`
  - `country-list`、`iso-639-1`
6. 交互/工程能力
  - 拖拽：`vuedraggable`
  - 可树选择：`@riophae/vue-treeselect`
  - 签名：`signature_pad`
  - 二维码：`@chenfengyuan/vue-qrcode`、`qrcodejs2`
  - 复制：`vue-clipboard2` + `clipboard`
7. 实时通信
  - `sockjs-client`、`stomp-websocket`

## 4. 如何使用本清单

1. 你可以用本文件做“模块验收目录”：登录/权限 → 进入首页 → 打开关键业务模块（如 `/order`、`/thepool`、`/isacommunity` 等）。
2. 如果需要“升级到 Vue3/Vite 的迁移对照表”，建议按模块选定验收链路，我可以把每条链路的关键组件与依赖也列成进一步文档。
